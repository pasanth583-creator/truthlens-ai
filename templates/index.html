Core Verification Capabilities

Built for rigorous, transparent, and explainable misinformation detection.

🤖

AI Classification

Production DistilBERT model fine-tuned across multi-domain datasets (ISOT & LIAR) for 3-class veracity detection: Reliable, Misleading, and False.

🧠

Explainable Predictions

Token-level Integrated Gradients reveal which words elevated or opposed the classification, ensuring complete transparency without black-box opacity.

🌐

Evidence Retrieval

Real-time query synthesis retrieves authoritative encyclopedic and fact-check records with zero citation hallucinations or fabricated URLs.

⚖️

Verification Signals

Explicit conflict detection flags cases where linguistic style differs from verified facts, ensuring external truth always supersedes model confidence.
